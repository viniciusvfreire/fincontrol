# FinControl 💰

Sistema de controle de gastos empresarial — projeto desenvolvido para a 
disciplina de Laboratório de Programação II (2º período).

## Tecnologias
- Python, SQLite, Flask, Bootstrap, bcrypt

## Como rodar
1. `python -m venv venv`
2. `venv\Scripts\activate`
3. `pip install -r requirements.txt`
4. `python main.py` (terminal) ou `python app.py` (web → localhost:5000)
